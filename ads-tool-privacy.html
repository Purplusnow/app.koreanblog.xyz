Purplusnow Ads Tool — Privacy Policy

Last updated: November 13, 2026 · Operated by Purplusnow (app.koreanblog.xyz)

What this tool is

Purplusnow Ads Tool is an internal tool used only by the Purplusnow team. It uses the Google Ads API to create and manage app install campaigns for Purplusnow's own games and apps, in Google Ads accounts owned by Purplusnow. It is not offered to the public and does not access any third party's Google Ads account.

Data the tool accesses

  • Campaign settings and performance data (budgets, bids, targeting, costs, conversions) of Purplusnow's own Google Ads accounts.
  • Ad creatives that Purplusnow prepares for its own apps (text, images, YouTube video links).

The tool does not request or store personal information about end users, does not use Google user data for advertising or profiling, and does not sell or transfer data to anyone.

How data is used and stored

Data is used only to create, update, review and report on Purplusnow's own campaigns. Copies of campaign plans and change logs are kept on Purplusnow's own computers. Access credentials are stored privately and are never published.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Purplusnow Ads Tool — 개인정보처리방침

최종 수정일: 2026년 11월 13일 · 운영: Purplusnow

도구 소개

Purplusnow Ads Tool은 Purplusnow 팀만 사용하는 내부 도구입니다. Google Ads API를 이용해 Purplusnow가 소유한 Google Ads 계정에서 자사 게임·앱의 설치 캠페인을 만들고 관리합니다. 외부에 제공하지 않으며 다른 사람의 Google Ads 계정에는 접근하지 않습니다.

접근하는 데이터

  • Purplusnow 소유 Google Ads 계정의 캠페인 설정과 성과 데이터(예산, 입찰, 타게팅, 비용, 전환)
  • Purplusnow가 자사 앱을 위해 준비한 광고 소재(문구, 이미지, YouTube 영상 링크)

최종 사용자의 개인정보를 요청하거나 저장하지 않으며, Google 사용자 데이터를 광고나 프로파일링에 사용하지 않고, 누구에게도 판매하거나 제공하지 않습니다.

이용 및 보관

데이터는 자사 캠페인의 생성·수정·검토·보고에만 사용합니다. 캠페인 계획과 변경 이력은 Purplusnow의 컴퓨터에 보관하며, 접근 인증 정보는 비공개로 보관하고 공개하지 않습니다.

Google API 서비스 사용자 데이터 정책

Google API로 받은 정보의 사용은 제한적 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.
